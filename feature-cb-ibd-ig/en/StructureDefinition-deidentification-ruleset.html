Logical Model: De-identification ruleset (model)

Official URL: https://ig.santeon.nl/sim-on-fhir/StructureDefinition/deidentification-ruleset Version: 0.1.0
Draft as of 2026-10-26 Computable Name: DeidentificationRuleset

A fully-resolved (effective) set of de-identification rules for one export. It carries the actual rules in force, with no reference to a base ruleset plus differences. Together with the export Parameters (which declare the released elements via _elements), it fully describes how an export is de-identified.

Usages:

  • This Logical Model is not used by any profiles in this Specification

deidentification-ruleset.id 1..1 string Ruleset identifier, e.g. 'santeon-default'.

deidentification-ruleset.url 0..1 uri Canonical URL, when this ruleset is a published resource.
deidentification-ruleset.rule C 1..* BackboneElement The de-identification rules in force for this export.
Constraints: none-requires-reason, hash-requires-algorithm, shift-requires-maxdays, clampage-requires-bounds
deidentification-ruleset.rule.path 1..1 string FHIRPath expression selecting the element(s) this rule applies to. A rule covers the named element and every element beneath it.
deidentification-ruleset.rule.action 1..1 code The transformation to apply.
Binding: De-identification Action Value Set (required)
deidentification-ruleset.rule.priority 0..1 integer Optional explicit ordering. For date elements the canonical order is shift, then first-of-month, then clamp-age; priority is for finer control.
deidentification-ruleset.rule.algorithm 0..1 code Hash algorithm (hash only), e.g. 'hmac-sha256'.
deidentification-ruleset.rule.maxDays 0..1 integer Maximum absolute date shift in days (shift only). Offset drawn from +/- maxDays, never zero.
deidentification-ruleset.rule.minAge 0..1 integer Lower age bound in years (clamp-age only).
deidentification-ruleset.rule.maxAge 0..1 integer Upper age bound in years (clamp-age only).
deidentification-ruleset.rule.exceptionReason 0..1 string Justification. Required for action 'none'; required when 'clamp-age' overrides the standard age range.
