Logical Model: Dataset definition (model)

Official URL: https://ig.santeon.nl/sim-on-fhir/StructureDefinition/dataset-definition Version: 0.1.0
Draft as of 2026-10-16 Computable Name: DatasetDefinition

One dataset (for example IBD or COPD): the cohort that forms the Group, and the KPI definitions whose data the export releases. The generator resolves a dataset into a Group (cohort as bulk-data member-filters) and a Parameters (_type, _typeFilter, _elements), and renders the whole definition as a readable page.

Usages:

  • This Logical Model is not used by any profiles in this Specification

You can also check for usages in the FHIR IG Statistics

dataset-definition 0..* Base Dataset definition (model)
dataset-definition.id 1..1 string Dataset identifier, e.g. 'ibd'.
dataset-definition.version 1..1 string Semantic version of this dataset definition.
dataset-definition.title 1..1 string Human-readable name.
dataset-definition.description 0..1 markdown What the dataset is for.
dataset-definition.cohort 1..1 BackboneElement Who is in the Group.
dataset-definition.cohort.description 0..1 markdown The cohort in words, including anything the criteria cannot express.
dataset-definition.cohort.criteria 1..* BackboneElement A member filter. A patient must satisfy every criterion.
dataset-definition.cohort.criteria.resource 1..1 code FHIR resource type the criterion searches.
dataset-definition.cohort.criteria.param 0..* BackboneElement A FHIR search parameter.
dataset-definition.cohort.criteria.param.name 1..1 string Search parameter name including modifier.
dataset-definition.cohort.criteria.param.value 1..1 string Search value; same reference syntax as in a KPI definition.
dataset-definition.cohort.postFilter 0..* BackboneElement Cohort logic that cannot be expressed as a FHIR search.
dataset-definition.cohort.postFilter.description 1..1 markdown What is filtered, in words.
dataset-definition.cohort.postFilter.expression 0..1 string Optional formalisation.
dataset-definition.kpi 1..* string Id of a KpiDefinition whose data the export releases.
dataset-definition.include 0..* BackboneElement Data the dataset releases that does not belong to any KPI, for example the Patient model with a filter on gender. Same shape as a KPI criterion.
dataset-definition.include.resource 1..1 code FHIR resource type.
dataset-definition.include.param 0..* BackboneElement A FHIR search parameter.
dataset-definition.include.param.name 1..1 string Search parameter name including modifier.
dataset-definition.include.param.value 1..1 string Search value; same reference syntax as in a KPI definition.
dataset-definition.include.element 0..* string Elements of the resource that must be released, as ElementName. Drives _elements and bounds the generated profile.
