# K3.6.3 Calprotectine voor scopie - SIM on FHIR v0.1.0

## K3.6.3 Calprotectine voor scopie

```
Denominator
|
├── Cohort IBD
|   │
|   ├── Patient
|   │     └── birthDate ≥ 18 jaar
|   │
|   └── EpisodeOfCare
|         ├── period.start ≥ 2018-01-01
|         ├── status = active
|         ├── type ∈ ValueSet: LocalZorgtypeCodes
|         └── diagnosis → ConditionSan (code ∈ ValueSet: LocalSpecialismeDiagnoseCodes)
|
└── Procedure
      ├── subject → PatientSan (IBD cohort)
      ├── code ∈ ValueSet: LocalVerrichtingCodesNZa
      └── performedPeriod.start

Numerator
|
├── Denominator
|
└── Observation
      ├── code ∈ ValueSet: Santeon_MetingNaamCodelijst
      └── effectiveDateTime ∈ [Procedure.performedPeriod.start - 90 dagen, Procedure.performedPeriod.start]

```

## IBD Cohort

Zie het [IBD Cohort](ibd-dataset.md#cohort) voor meer details.

## Measure

Definitie: Kwaliteitsindicator die het percentage scopieën meet waarbij in de 90 dagen voorafgaand aan de scopie ten minste één fecaal calprotectinemeting is uitgevoerd.

**Denominator:** [IBD Cohort](ibd-dataset.md#cohort) **met scopie** ([LocalVerrichtingCodesNZa:](ValueSet-local-verrichting-codes-nza.md) `034620`, `034686`, `034690`, `035582`). (De numerator van [indicator K3.1.2.](K312.md#measure))

**Numerator:** IBD cohort **met scopie** ([LocalVerrichtingCodesNZa:](ValueSet-local-verrichting-codes-nza.md) `034620`, `034686`, `034690`, `035582`) waarbij tot 90 dagen voorafgaand aan de scopie een calprometing (LOINC `38445-3`) is gedaan.

## FHIR query

**Denominator**

```
// Cohort:

GET [base]/Patient?
  birthdate=le[Peildatum-18J]

GET [base]/EpisodeOfCare?
  type:in=ValueSet/LocalZorgtypeCodes&
  status=active&
  period-start=ge2018-01-01

GET [base]/Condition?
  code:in=ValueSet/LocalSpecialismeDiagnoseCodes

```

```
GET [base]/Procedure?
  subject={patient}&
  code:in=ValueSet/LocalVerrichtingCodesNZa
  // *Business rule uses: performedPeriod.start

```

**Numerator**

```
GET [Denominator]

GET [base]/Observation?
  subject={patient}&
  code:in=ValueSet/Santeon_MetingNaamCodelijst|http://loinc.org:38445-3
  // *Business rule: effectiveDateTime >= Procedure.performedPeriod.start - 90 dagen & <= Procedure.performedPeriod.start

```

**Tenzij anders vermeld, voldoen alle FHIR-resources in de queries aan de bijbehorende [Santeon-profielen](profiles.md).**
