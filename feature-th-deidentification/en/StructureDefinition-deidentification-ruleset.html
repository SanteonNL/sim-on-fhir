Logical Model: De-identification Ruleset

Official URL: https://ig.santeon.nl/careplan/StructureDefinition/deidentification-ruleset Version: 0.1.0
Draft as of 2026-09-23 Computable Name: DeidentificationRuleset

A fully-resolved (effective) set of de-identification rules for one export. It carries the actual rules in force, with no reference to a base ruleset plus differences. Together with the export Parameters (which declare the released elements via _elements), it fully describes how an export is de-identified.

Usages:

  • This Logical Model is not used by any profiles in this Specification

deidentification-ruleset 0..* Base De-identification Ruleset
id 1..1 string Ruleset identifier, e.g. 'santeon-default'.
version 1..1 string Semantic version of this ruleset.
url 0..1 uri Canonical URL, when this ruleset is a published resource.
rule C 1..* BackboneElement The de-identification rules in force for this export.
Constraints: none-requires-reason, hash-requires-algorithm, shift-requires-maxdays, clampage-requires-bounds
path 1..1 string FHIRPath expression selecting the element(s) this rule applies to. A rule covers the named element and every element beneath it.
action 1..1 code The transformation to apply.
Binding: De-identification Action Value Set (required)
priority 0..1 integer Optional explicit ordering. For date elements the canonical order is shift, then first-of-month, then clamp-age; priority is for finer control.
algorithm 0..1 code Hash algorithm (hash only), e.g. 'hmac-sha256'.
propagateTo 0..* string Reference paths rewritten with the same hash (hash on an id element), e.g. '*.subject', '*.patient'.
maxDays 0..1 integer Maximum absolute date shift in days (shift only). Offset drawn from +/- maxDays, never zero.
minAge 0..1 integer Lower age bound in years (clamp-age only).
maxAge 0..1 integer Upper age bound in years (clamp-age only).
exceptionReason 0..1 string Justification. Required for action 'none'; required when 'clamp-age' overrides the standard age range.
